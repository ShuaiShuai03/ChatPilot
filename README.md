# ChatPilot

ChatPilot 是一个本地运行的 Chrome Manifest V3 扩展，服务于 **https://chatgpt.com/**。它可以浏览、搜索、选择和导出当前对话；全部处理都在浏览器内完成。

## 安装与开发

需要 Node.js **22.12+** 和 pnpm，仓库中的 lockfile 固定依赖版本。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

WXT 会在 `postinstall` 生成 TypeScript 配置。如果安装时禁用了脚本，请先运行：

```sh
pnpm exec wxt prepare
```

## 在 macOS Chrome 中加载

```sh
pnpm build
```

1. 在 Chrome 打开 `chrome://extensions/`。
2. 开启「开发者模式」。
3. 选择「加载已解压的扩展程序」。
4. 选择 项目目录下的 `.output/chrome-mv3/`。
5. 打开或刷新 ChatGPT 对话，在右侧点击 ChatPilot 浮动入口。

重新构建后，在扩展程序页面点击「重新加载」，再刷新 ChatGPT 页面。开发构建与上述生产目录相互独立。

## 使用方式

- 搜索覆盖已发现消息的完整文本，不受列表预览长度限制，也不会改变选择或导出范围。
- 点击列表消息可跳转到原消息；高亮项随当前阅读位置更新。
- 「全选」「清除」「仅我的消息」「仅 ChatGPT 消息」和每条消息的复选框均基于同一份规范消息列表；搜索结果不影响选择。
- 选择全部、仅 ChatGPT 或已选消息，并选择 Markdown、JSON 或文本格式后导出。没有已选消息时，已选范围导出会保持禁用并给出提示。
- 「加载完整对话」会收集 ChatGPT 已卸载但仍可通过页面访问的历史。完整和仅 ChatGPT 导出会自动执行收集；已选导出只刷新所选消息。
- 工具栏弹窗可设置导航器显示、平滑滚动、默认导出格式/范围与宽度（260–420px）。系统的减少动态效果偏好会覆盖平滑滚动。

### 用户消息上下跳转

右侧提供两个 36px 浮动按钮，只定位用户消息。在会话底部首次点击「↑」时，会跳到最新一条用户消息；之后按上一次跳转结果严格相邻地向上或向下移动。手动滚动或点击消息列表会清除这条跳转序列，下一次操作重新从当前可见位置计算。

按钮在面板收起时仍可使用，展开时与面板并排且保持固定横向位置；到达首尾后禁用对应方向。按钮周围透明区域不会拦截页面点击。搜索、选择和导出范围不影响跳转。界面使用简体中文，导出中的用户角色标题为「用户」，JSON 字段和角色枚举保持兼容。

目标消息的正文如果被虚拟列表卸载，ChatPilot 会按需加载后再跳转。该过程可取消、有单步和总时限，并在 SPA 路由切换时失效，避免旧对话操作影响新对话。它不注册全局快捷键，也不修改输入框或页面原有键盘行为。

跳转只移动当前会话的滚动容器，将消息开头对齐阅读区域；虚拟列表重排后会在时限内校正位置。页面自动调整滚动位置不会清除连续跳转游标，实际滚动会按帧刷新方向按钮状态。没有持久消息外壳时，优先定位已连接的邻近候选；只有候选不可达或边界尚不确定时才尝试完整收集。

历史收集显示进度和取消按钮；达到时限、移动次数上限或单步加载失败时会停止。完成或取消时会恢复原阅读锚点；用户主动滚动或与对话交互后会保留新位置。未完整收集或 ChatGPT 仍在生成时，不会作为完整导出下载。

## 验证

```sh
pnpm exec playwright install chromium
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
```

`test:e2e` 会先构建生产扩展，再将同一 MV3 目录加载进临时 Chromium 配置。浏览器测试只在 ChatGPT 域名上提供本地合成页面，并阻断其他 HTTP(S) 请求；不需要生产登录、账户数据、额外主机权限或虚拟后台脚本。请使用 Playwright 自带 Chromium，不要使用系统 Chrome 或 Edge 的命令行旁加载方式。

单元测试使用 Vitest 和 Linkedom。合成夹具覆盖富文本、代码、表格、数学公式、图片、附件、隐藏推理、多块回答、身份、排序、选择和增量更新。浏览器测试覆盖真实扩展加载、虚拟历史、SPA 路由、选择、实际下载内容与不同桌面宽度布局。已登录页面的 DOM 检查只能作为兼容性抽查，不能替代扩展验收。

本轮检查结果与证据范围见 [验证记录](VALIDATION.md)。

## 架构

- `src/adapters/chatgpt/`：可见 DOM 解析、稳定轮次外壳、已连接正文索引、增量观察、当前消息跟踪和有界历史收集。ChatGPT 标记变化应在此适配。
- `src/conversation/`：规范 `MessageRecord[]`、选择和当前消息状态、快照契约、导航与生命周期协调。
- `src/components/`：React 导航界面，展开时才挂载；只消费规范记录，不解析宿主页面。
- `src/export/`：纯 Markdown/JSON/TXT 格式化、范围筛选、安全文件名和 Blob 下载。
- `entrypoints/`：WXT 内容脚本 Shadow DOM 集成与设置弹窗。

解析器同时生成正文、预览和 Markdown。身份优先使用消息 ID，其后是轮次标识、测试 ID，最后才是确定性内容哈希；同一逻辑轮次中的多段 ChatGPT 回答会按 DOM 顺序合并。缓存记录可穿过正文虚拟化，真实分支替换会清除旧回答的选择。每个 SPA 对话都有代际标记，异步操作不能把旧结果写入新对话。

## 隐私与限制

- 仅请求 `storage` 权限，并只匹配 `https://chatgpt.com/*` 内容脚本；Shadow DOM 样式是仅限该域名的本地扩展资源。
- 设置保存在本地扩展存储中；对话内容、索引和选择仅保留在标签页内存，不会持久化或上传。
- 没有后端、数据库、分析或遥测、远程脚本、令牌访问、私有 ChatGPT API、ChatGPT React 内部调用或 `fetch` 劫持。
- 下载使用内存 Blob 和临时链接，不请求 Chrome `downloads` 权限。导出中会保留可见链接地址，但不会抓取链接内容。
- 只处理用户可见的对话内容；隐藏推理、控件与折叠推理正文会被排除。可见但不在视口内的正文可被收集，扩展不会展开隐藏推理或修改账户数据。
- 「完整」指稳定且可从 DOM 到达的对话，不代表服务器上不可访问的历史或其他分支。标记缺失、含义不明确或仍在生成时会显示不完整状态；等待 ChatGPT 渲染完成后可重试。
- Markdown 保留代码和语义化表格/公式，不承诺像素级版式。没有语言标记时不会猜测；图片导出为链接或替代文本，临时或鉴权链接可能失效。

本仓库仅用于本地开发和解压加载，不包含商店提交、发布、部署或自动对外通信。
